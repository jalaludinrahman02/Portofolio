# 🌐 Personal Portfolio - Ahmad Jalaludin Rahman

Repository ini berisi kode sumber (*source code*) untuk website portofolio pribadi saya. Website ini dirancang dengan tema *cyberpunk/terminal* modern berbasis warna biru cyan untuk menampilkan latar belakang akademis, keahlian, serta proyek-proyek di bidang **Data Science**, **Data Analytics**, dan **Applied Statistics**.

🔗 **Live Demo:** [jalaludinrahman02.github.io/Portofolio/](https://jalaludinrahman02.github.io/Portofolio/)

---

## ✨ Fitur Utama

- **Hero & About Me:** Ringkasan latar belakang akademis di Statistik Universitas Brawijaya serta fokus keahlian sebagai Data Scientist & Data Analyst.
- **Dual Language Switcher:** Fitur peralihan bahasa instan (Indonesia & Inggris) untuk kenyamanan pengunjung.
- **Featured Projects:** Galeri proyek pilihan lengkap dengan deskripsi, *tech stack*, dan akses langsung ke laporan/dokumentasi Google Drive.
- **Work Experience & Credentials:** Kartu riwayat pengalaman kerja dan lisensi/sertifikasi profesional dengan badge kategori yang responsif.
- **Interactive UI & Terminal Style:** Tampilan estetik ala antarmuka kode, fitur salin email instan, serta integrasi foto profil AI scanner overlay.
- **Responsive & Lightweight:** Tampilan adaptif yang cepat dimuat dan nyaman diakses dari perangkat mobile maupun desktop.

---

---

## 📌 Proyek yang Ditampilkan dalam Portofolio

1. **Model Risko Kredit Multifinance**
   - *Metode / Tools:* Logistic Regression, Random Forest, R, Python
   - *Deskripsi:* Pemodelan end-to-end credit risk untuk evaluasi kelayakan kredit dan prediksi default nasabah multifinance.

2. **Regionalisasi & Clustering Spasial Jawa Timur**
   - *Metode / Tools:* SKATER Algorithm, K-Means Clustering, R (`spdep`, `igraph`), ArcMap
   - *Deskripsi:* Pengelompokan 38 wilayah administratif Jawa Timur berdasarkan indikator ekonomi, demografi, dan tenaga kerja informal.

3. **Dashboard & Data Cleaning HR Capital**
   - *Metode / Tools:* Power BI, Microsoft Excel, VLOOKUP, Data Validation
   - *Deskripsi:* Pembersihan dataset internal HR dan pembuatan dashboard visual interaktif untuk monitoring performa serta profil SDM.
